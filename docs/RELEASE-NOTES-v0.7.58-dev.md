# Capital & Consequence v0.7.58-dev

**Development source checkpoint, not an accepted Linux release.**

The computer boxer now expends round stamina for movement and for defending against a player's punch. When exhausted, its pursuit speed falls, rather than silently allowing endless full-speed footwork. The existing no-mid-round-regeneration and partially recovering between-round fatigue rules remain intact. The practice HUD now displays opponent stamina, making both fighters' exhaustion readable. Offline model regressions were expanded to check movement drain, exhausted pursuit and guard costs.

All sparring remains practice only. No transfer to saved health, real-world clock, betting, career finances, championship records, or persistent injuries. No GitHub Actions or external assets. Actual Ubuntu Electron/UI testing remains outstanding.
