# v0.7.98-dev · In-place updater no longer leaves source archives

November 3, 2026; dev source only. Removed automatic timestamped `.tar.gz` snapshots and any writes to the persistent `~/DKLab/Archives` tree from `scripts/build-from-github.py`. Existing source is still updated in place, with short-lived recovery copies under the update's `TemporaryDirectory` so a partially failed source synchronization can be restored. Added `tests/linux-in-place-builder.cjs` to check policy and exercise the Python `synchronize` procedure on fixture source files; JavaScript test syntax passed, actual native Python test has not been executed here. Important: on a user's machine with the old updater installed, invoking the *old local script* runs old backup-writing code, even though it fetches new sources; bootstrap the new GitHub script directly for first test. Complete native source regression, in-place build and Ubuntu Electron UI are still unverified. No accepted executable/tag.
