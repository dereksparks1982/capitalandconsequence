# v0.7.95-dev · Passenger dominoes

November 3, 2026. Source-only development, not an owner-accepted release.

At the existing walkable steamship or schooner saloon card-table tile, Charles can now play a complete zero-stakes double-six dominoes hand. It uses all 28 tiles, seven each to player and computer opponent, actual boneyard, legal left or right placement, draw-until-playable, forced pass only when blocked, fair blocked pip scoring, and resumable save state including last 30 results. Resign is available without a time charge. Twenty-One, checkers and dominoes cannot begin while another saloon match is unfinished.

Every paid game action uses the existing shared Washington world simulation with 3, 5 or 10 minutes, so the current real passenger itinerary keeps moving and the weather/arrival remain authoritative. No wagering, invented fare, ship treasury, new character backstory, origin voyage, fixed map change, or alternate ship clock. Changed: new `merchant-shipboard-dominoes.js`, UI, CSS, existing checkers/card interlock, app action, version, and dedicated regression.

Verified here: JS syntax of six source/test files; connector-side V8 game model from shuffle to settlement (one full hand). NOT verified: native complete Node source suite, Electron boot/render/gameplay on Ubuntu, accepted Linux artifact or owner playtest. Do not tag as a release.
