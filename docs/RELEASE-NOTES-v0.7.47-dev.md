# Capital & Consequence v0.7.47-dev

Source build of October 31, 2026, not an accepted release.

Introduces an independent, playable top-down boxing practice ring in the existing Licensed Boxing panel. Movement is WASD, left click punches, hold right click blocks. Three rounds have partial stamina recovery and a declining maximum stamina pool. Existing 32x32 artwork, room collision and pathfinding are reused. No new libraries, copied third-party code, online service or GitHub Actions.

The feature is practice-only: no changed cash, wagers, boxing championships, injuries, saved life state or Washington clock. Headless mechanics tests included. Linux Electron visual/controls testing pending. See docs/TOPDOWN-ROOMS-AND-BOXING-2026-10-31.md.
