# Capital & Consequence v0.7.56-dev: portable purchased provisions

The existing market player bag is now accessible under Personal Journal as **Carried Provisions**. An item really purchased at an existing Chinatown or Hillsdale merchant can be eaten later, even after the character has left the counter, as long as it is edible and in the same saved personal bag. Consumables are displayed with original purchase dates. The action charges ten minutes of Washington time, removes the exact saved item, updates hunger/thirst, respects the half-hour meal interval, writes a private journal record and autosaves the existing profile.

This does not create remote purchases, free stock, a teleport, a hunger notification option list or complete home/restaurant service. Existing market stock, merchant accounts and item ownership remain authoritative. Development source only, pending Ubuntu testing. No GitHub Actions, extra package or new map geometry.
