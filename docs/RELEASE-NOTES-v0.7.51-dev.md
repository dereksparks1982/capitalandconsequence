# Capital & Consequence v0.7.51-dev: location-bound hospital treatment

Large connected health milestone. Existing District General Hospital reception, registered as governmentHospital/reception, now offers physician examination (15 Washington minutes, $2 personal) or limited treatment (45 minutes, $8 personal, up to 28 health). Only a player actually present at the non-developer hospital reception, with sufficient saved game time and personal money, can use the controls. Records the care in the existing player journal and saves to the active profile. Not available from unrelated rooms, restricted wards or the morgue. No new pins, map art changes, remote travel, free heals or duplicate corporate accounting.

This does not implement complete medical care, infections, insurance or hospitalization. Actual Ubuntu graphical QA and full offline Node regression run remain pending. No GitHub Actions or user testing commands.
