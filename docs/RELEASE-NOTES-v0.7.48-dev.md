# Capital & Consequence v0.7.48-dev\n\nDevelopment source update, not an accepted Linux executable. The independent top-down sparring module now records scored rounds, chooses a winner for a decision (or a draw on equal scores), and identifies the winner in knockouts and referee stoppages. Blocked attacks and landed hits contribute to simplified practice scoring. New offline regression assertions cover opponent victory, draw, scorecard completeness, and knockout winner.\n\nThe scoring is a simplified design placeholder, not an official boxing commission rules model. No changes to saved game state, character health, championship standings, world time, wagering, the original city map, or approved geometry. No GitHub Actions. Full local test suite and graphical Linux playtesting are not verified for this source update.\n
